# Дневник эмоций — Telegram Mini App

Телеграм мини-приложение для отслеживания эмоционального состояния. Помогает вести дневник эмоций, анализировать паттерны и подводить итоги.

## Возможности

- **Запись эмоций** — 16 эмоций с интенсивностью (1-10) и заметками
- **Напоминания** — бот напоминает каждый час в настроенном промежутке дня
- **История** — просмотр записей по дням с таймлайном
- **Графики** — визуализация по дню, неделе и месяцу (Chart.js)
- **Итоги** — рефлексия по дню, неделе и месяцу с подсказками

## Установка и запуск

### 1. Создайте бота

Получите токен у [@BotFather](https://t.me/BotFather) в Telegram.

### 2. Настройте окружение

```bash
cp .env.example .env
# Отредактируйте .env — укажите BOT_TOKEN и WEBAPP_URL
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Запустите

```bash
# Всё вместе (для разработки):
python run.py

# Или раздельно (для продакшена):
python -m bot.bot &
gunicorn webapp.app:app -b 0.0.0.0:5000
```

### 5. Настройте Mini App

В BotFather → `/mybots` → выберите бота → `Bot Settings` → `Menu Button` → укажите URL вашего веб-сервера.

## Конфигурация

| Переменная | Описание | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен Telegram-бота | — |
| `WEBAPP_URL` | URL мини-приложения | — |
| `REMINDER_START_HOUR` | Начало напоминаний | 9 |
| `REMINDER_END_HOUR` | Конец напоминаний | 22 |

## Деплой

Для деплоя Mini App нужен HTTPS. Варианты:
- **Railway / Render** — бесплатный хостинг с HTTPS
- **VPS + nginx + certbot** — для полного контроля
- **ngrok** — для тестирования локально
